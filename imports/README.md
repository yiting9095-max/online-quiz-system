# 官方技能檢定題庫匯入檔

本資料夾提供符合本專案 Supabase `public.questions` 資料表格式的 CSV。

## 匯入前請讀

- 題目來源：勞動部勞動力發展署技能檢定中心公開的技能檢定學科測試參考資料。
- 官方題庫入口：https://techbank.wdasec.gov.tw/
- 官方網站資料開放宣告：https://www.wdasec.gov.tw/cp.aspx?n=EAB483BB24D56F64
- 來源題目與答案的版本資訊記錄於每一列的 `source_name`。

## 匯入步驟

1. 到 Supabase Dashboard，開啟這個測驗系統使用的專案。
2. 進入 **Table Editor → questions**。
3. 選 **Insert → Import data from CSV**（不同介面版本文字可能略有差異）。
4. 一次匯入一個 CSV，先匯入專業科目，再匯入四個共同科目。
5. 確認欄位對應後完成匯入。五個 CSV 都要各匯入一次。

**請勿重複匯入同一個檔案**，否則會產生重複題目。若匯入中途出錯，先檢查 `questions` 資料表已新增的筆數，再決定如何繼續。

## 圖形題

來源資料有 66 題標記為含圖題。因目前前端尚未顯示題目圖示或圖片選項，這 66 題在 CSV 中先設為 `is_active=false`，並在 `explanation` 欄註明原因，以免使用者在看不到圖的情況下答題。文字題設為啟用。這些停用題目已保留在資料庫，待網站完成圖片題支援和題圖核對後再啟用。

## 重要欄位

- `category`: `professional`（專業科目）或 `common`（共同科目）。
- `options`: JSON 陣列。
- `correct_index`: 0 起算。
- `source_name`: 官方來源檔名、版次與來源題號。
- `source_page`: 題目在來源 PDF 的頁碼。
- `is_active`: 無需題圖的題目為 `true`；含圖題暫為 `false`.

題庫由本專案用於個人考試練習。題庫原始來源及相關權利說明請以技能檢定中心官方公告為準；使用時請標示原始來源，不應暗示本測驗網站由政府機關認可或營運。
